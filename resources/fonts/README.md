# Fonts

The editor embeds these fonts (compiled into the plugin binary as `TLFonts` binary data). All
three families are licensed under the SIL Open Font License 1.1; each licence text sits next to
its fonts and ships with the source.

| File | Family | Licence | Notes |
|---|---|---|---|
| Marcellus-Regular.ttf | Marcellus (Astigmatic) | OFL 1.1, Reserved Font Name "Marcellus" (OFL-Marcellus.txt) | Unmodified upstream file |
| Jost-Light.ttf, Jost-Regular.ttf | Jost (indestructible type*) | OFL 1.1, no Reserved Font Name (OFL-Jost.txt) | Static weight 300 and 400 instances made with fontTools from the upstream variable font `Jost[wght].ttf` |
| DMMono-Regular.ttf, DMMono-Medium.ttf | DM Mono (Colophon for Google) | OFL 1.1 (OFL-DMMono.txt) | Unmodified upstream files |

Sources: the Google Fonts repository (`ofl/marcellus`, `ofl/jost`, `ofl/dmmono`).

The OFL permits embedding the fonts in software, including commercial software, as long as the
fonts are not sold on their own and the licence travels with them. Keep these licence files in
the repository and include them (or this folder) in any installer or release notes.
